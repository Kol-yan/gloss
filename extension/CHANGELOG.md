# Changelog

Changes to the gloss browser extension.

## 1.0.0 — First public release

### Features

* **Add to My words.** Select a word or a short phrase on any site,
  right-click and choose **Add to My words**. A small notice confirms it and
  lets you add a meaning in your own words.
* **Highlight My words.** A switch in the toolbar popup marks the words from
  My words on the current page. Hover a marked word to see its meaning.
* **Writing checks in any text field.** After you pause typing, mistakes are
  underlined: corrections in red, style notes in blue. **Apply** fixes the
  text so that Ctrl+Z still undoes it; **Dismiss** hides the suggestion.
* **Per-site control.** Turn checks off for one site in the popup, or for all
  sites in the settings. Password fields, fields for names, emails, card
  numbers and one-time codes, and fields that opt out are never checked.
* **Check with gloss.** Open the selected text in the gloss editor.
* **No sign-in.** The extension uses the gloss workspace of this browser; the
  popup offers **Open gloss** when there is none yet.
* **Your own server.** Works with gloss.li by default; a self-hosted server can
  be set in the settings, with **Check connection** to confirm it works.
* Supports Chrome, Edge and other Chromium browsers. Firefox is not supported
  yet.
